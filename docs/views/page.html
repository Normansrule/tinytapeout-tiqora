Inside a gate

Tiqora-Serial at four depths: the SystemVerilog it is written in, the {{v:cells}} standard cells synthesis turns it into, the transistors inside each cell, and how those transistors are drawn in silicon.

Everything below comes from real files: the RTL in src/, a Yosys {{v:yosys}} synthesis to the SkyWater sky130 high-density cell library ({{v:area}} µm², {{v:transistors}} transistors counted from the SkyWater SPICE netlists), and the SkyWater layouts of the {{v:celltypes}} cell types it uses. docs/tools/views_build.py builds it; nothing on this page is drawn by hand.

How to use it

Every highlighted thing is a viewing point: choose it and every view that can show it follows. Choose a module on the left, then a register: its RTL lines light up and the gates that compute its next value are drawn. Choose a gate to open its transistors and layout. Flip the inputs and watch which transistors conduct. Below, the state machine is a common language between the views: a state is a case arm in the RTL, one flip-flop in the gates, and a circle in the diagram. The address bar keeps your place, so a view can be linked.

How each view is checked

  • Layout is the transistors. KLayout's netlist extractor rebuilds the circuit from each cell's polygons and compares it with the SkyWater SPICE netlist, transistor by transistor (type, width, length, connections): python3 docs/tools/views_lvs.py. A second, independent geometric check measures every channel: python3 test/views/mini_lvs.py.
  • The transistors are the gate. A switch-level simulation of each cell's transistors, for every input combination, must give the liberty Boolean function; flip-flops must load D on a rising clock and hold otherwise: python3 docs/tools/views_switch.py. The transistor view on this page uses the same rules, and test/views/page_test.js checks the two agree on every cell.
  • The gates are the RTL. The gate netlist and the RTL run side by side on the same host traffic (pings, register reads and writes, stray bytes and short glitches on the serial line, and random resets), with random capture-pin activity, and every output pin is compared on every clock: make -C test views.
  • The diagrams are what the chip does. The same runs log the serial receiver's state machine every clock; each step must be an arrow of the diagram, and the gate flip-flops must hold the one-hot code synthesis chose: python3 test/views/fsm_check.py.
