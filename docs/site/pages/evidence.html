Evidence

A chip project climbs one ladder: tested RTL, then synthesis, layout, timing, a shuttle, a fabricated chip, a measured chip. Each rung says whether it has been reached at the tile size this repository submits, and names the run that showed it. Results from the experimental 2x2 copy are shown on the rungs they belong to, and labelled.

Labels: measured a tool run produced it · experimental measured on a 2x2 copy, not the submitted 1x2 · failed run and did not pass · not yet not run or not reachable yet.
