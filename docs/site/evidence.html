Evidence

A chip project climbs one ladder: tested RTL, then synthesis, layout, timing, a shuttle, a fabricated chip, a measured chip. Each rung says whether it has been reached at the tile size this repository submits, and names the run that showed it.

Check it yourself

make -C test sim                          # every suite, including the recorded session
make -C test area                         # cell area with the real sky130 library
python3 docs/tools/atlas.py --check       # the atlas still matches the RTL
python3 docs/tools/traces.py --check      # the tours still match a fresh simulation
python3 docs/tools/check_site.py          # the site, its models and its pinout

Tiqora-Serial is Tiqora's timing unit with a serial host port instead of a processor, for a Tiny Tapeout 1x2 tile on SkyWater sky130. Nothing on these pages has run on real silicon or a real FPGA board; every number says how it was obtained.
